# 마이링크 (my-link) 사용자 시나리오 (User Scenarios)

> 본 문서는 PRD를 바탕으로 작성된 사용자 행동 흐름도 명세서입니다. 
> 모든 시나리오는 직관적인 와이어프레임 설계를 위해 `"사용자는 __하기 위해 __한다"` 규격을 따릅니다.

---

## 1. 방문자 (Visitor): 마이링크 페이지 방문 및 상호작용 과정

### 👁️ 접속 및 프로필 인지
* 방문자는 특정 소유자의 통합 링크 목록을 한눈에 확인하기 위해 **URL(`domain.com/닉네임`)을 클릭하여 접속한다.**
* 방문자는 현재 페이지가 누구의 소유인지 파악하기 위해 **화면 최상단의 아바타, 닉네임(`displayname`), 소개글을 확인한다.**

### 🖱️ 링크 탐색 및 이동
* 방문자는 자신이 원하는 목적지(SNS, 포트폴리오 등)를 찾기 위해 **화면에 배치된 링크 버튼 목록을 상하로 스크롤한다.**
* 방문자는 버튼의 성격을 텍스트를 읽기 전 직관적으로 파악하기 위해 **버튼 좌측에 연동된 구글 파비콘(아이콘) 이미지를 참고한다.**
* 방문자는 실제 목적지 웹사이트로 넘어가기 위해 **원하는 링크 버튼을 클릭한다.**

### 📤 프로필 공유액션
* 방문자는 유용하다고 생각된 소유자의 마이링크 프로필을 타인에게 전달하기 위해 **화면에 배치된 '공유 버튼'을 누른다.**
* 방문자는 클립보드에 자동 복사된 프로필 주소를 카카오톡 등 외부 채널에 바로 붙여넣기 위해 **공유를 완료한다.**

---

## 2. 소유자 (Owner): 링크 추가/수정/삭제 과정 (인라인 편집 중심)

### ✍️ 관리 모드 및 편집 활성화
* 소유자는 내 페이지의 내용을 직접 편집하기 위해 **구글 계정 연동을 통해 서비스에 로그인한다.**
* 소유자는 결과물을 방문자 시점과 동일하게 즉시 확인하며 다듬기 위해, **자신의 프로필 페이지 위에서 '인라인 편집 모드'를 활성화한다.**

### ➕ 링크 추가 과정
* 소유자는 새로운 이동 경로를 방문자에게 제공하기 위해 **편집 화면 내의 `[링크 추가]` 버튼을 클릭한다.**
* 소유자는 방문자가 도달할 최종 주소를 설정하기 위해 **출력된 인라인 폼의 'URL 입력칸'에 주소를 기입한다.**
* 소유자는 해당 버튼이 어떤 링크인지 알리기 위해 **'제목(버튼 텍스트) 입력칸'에 안내 문구를 적는다.**
* 소유자는 폼에 작성한 내용을 실제 자신의 페이지에 반영하고 파비콘을 렌더링하기 위해 **하단의 `[저장]` 버튼을 누른다.**

### 🔄 링크 수정 패턴
* 소유자는 이전에 등록해 둔 링크의 제목이나 주소(URL)에 오타가 있거나 목적지가 바뀌었을 때 이를 변경하기 위해 **해당 링크 옆에 있는 `[수정]` 아이콘을 클릭한다.**
* 소유자는 올바른 정보로 갱신하기 위해 **활성화된 폼에서 텍스트를 수정한다.**
* 소유자는 수정한 변경 사항을 확정 짓기 위해 **`[저장]` 버튼을 누른다.**
* (별도 조작) 소유자는 이벤트 종료 등으로 링크를 비공개 처리하되 영구 삭제는 피하기 위해 **링크 옆에 있는 `[노출 On/Off 토글]`을 클릭하여 가린다.**

### 🗑️ 링크 삭제 과정
* 소유자는 더 이상 어떠한 이점도 제공하지 않는 불필요한 링크를 완전히 없애기 위해 **해당 링크의 `[삭제]` 아이콘을 클릭한다.**
* 소유자는 실수로 링크가 지워지는 것을 방지하기 위해 팝업된 재확인 모달에서 **`[확인(삭제 진행)]` 버튼을 눌러 작업을 완전히 종료한다.**
